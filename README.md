# zilc
Zero-inflated linear-circular regression

R codes for the paper "Spline regression for zero-inflated circular data".

The files sim_1.R and sim_2.R contain the codes for the simulation studies, based on the ZIvM 1/ZIJP 1 models and ZIvM 2/ZIJP 2 models, respectively. 

The files zivm.R and vmsp.R contain the codes for the data analysis using the ZIvM models and the von Mises Spline (vMSp) model, respectively.
