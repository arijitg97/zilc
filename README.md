# zilc
Zero-inflated linear-circular regression

R codes for the paper "Spline regression for zero-inflated circular data"

The files sim_1.R and sim_2.R contain the codes for the simulation studies, while zivm.R and vmsp.R contain the codes for the data analysis using the Zero-inflated von Mises (ZIvM) models and the von Mises Spline (vMSp) models, respectively.
